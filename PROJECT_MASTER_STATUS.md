## 22. Ten-day low-cost AI coding plan

Because GitHub Copilot credits are exhausted and the budget is limited, the recommended approach is not to purchase Copilot Pro+, Max, or another expensive high-model plan. The preferred order is to check Copilot Student eligibility, use local Ollama with Continue, use Cline or Aider only for narrow agent/terminal tasks, reserve existing high-quality AI access for architecture and difficult debugging, and consider Copilot Pro for one month only as a last resort if local AI is unusably slow.
