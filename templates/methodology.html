Methodology

Production pipeline built for local ML, explainability, and fast iteration.

The platform blends resume text, automation-risk modeling, O*NET clusters, and the optional Llama 3 narrative layer into a single request-response flow.

Team standard

Arpan, Umanga, and Samir can iterate independently because the app is split into templates, static assets, model training, and a small API surface.

Flask scikit-learn Ollama O*NET

1. Ingest

Load automation_risk.csv, resume_corpus.csv, coursera_catalog.csv, and the O*NET files. The training script also tolerates the current filename typo for the skills file.

2. Vectorize

Fit one TF-IDF vocabulary across job risk rows, resume corpus language, and O*NET skill profiles so similarity works across both candidate text and occupational language.

3. Predict

Use the local model for immediate risk scoring and role matching, then optionally pass the structured result to Ollama for a richer career narrative.

4. Recommend

Generate a learning roadmap using the course index and the strongest skill overlaps with the top matched occupational clusters.
