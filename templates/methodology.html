Methodology

Production pipeline built for local ML, explainability, and fast iteration.

The platform blends resume parsing, occupation matching, a historical occupation reference, published E0/E1/E2 task-exposure retrieval, O*NET clusters, and an optional local Llama explanation layer.

Team standard

Arpan, Umanga, and Samir can iterate independently because the app is split into templates, static assets, model training, and a small API surface.

Flask scikit-learn Ollama O*NET

1. Ingest

Load automation_risk.csv, resume_corpus.csv, coursera_catalog.csv, and the O*NET files. The training script also tolerates the current filename typo for the skills file.

2. Vectorize

Fit one TF-IDF vocabulary across job risk rows, resume corpus language, and O*NET skill profiles so similarity works across both candidate text and occupational language.

3. Predict

Use the local model for the historical occupation reference and role matching, retrieve published E0/E1/E2 labels for the matched occupation, then optionally pass the verified structured result to Ollama for explanation only.

4. Recommend

Generate a learning roadmap using the course index and the strongest skill overlaps with the top matched occupational clusters.

Deployment posture

The app never writes resumes to a permanent database. If advanced mode is enabled, only verified structured results (not the full resume) are posted to the local Ollama endpoint. Ollama never recalculates scores or labels.
